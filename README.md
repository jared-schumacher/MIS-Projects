# MIS Projects

A portfolio of business intelligence and data analytics projects created inside and outside of class.


## Carson College Academic Performance & Revenue Analytics

This project builds an end-to-end data pipeline that transforms raw, unorganized university data into actionable institutional insights. Using data inspired by Washington State University’s Carson College of Business, the project models a relational database containing **720+ individual records** across three core entities: students, courses, and enrollment.

*DISCLAIMER: The data in this project is entirely synthetic and was created using Mockaroo for learning purposes only*

---

## Purpose
The purpose of this project is to provide executives with data-driven answers to important operational and financial questions. By bridging the gap between database backend structures and front-end business analytics, this system automates the tracking of student major density, isolates academic risk factors by ranking course difficulty, and builds a precise department-level tuition revenue model.

---

## Tasks Performed
* **Database Schema Design:** Architected a relational database model from scratch, defining data types, primary keys, and foreign key relationships to link Students, Courses, and Enrollment tables.
* **Mock Data Generation & Cleaning:** Simulated 720+ rows of realistic academic records using Mockaroo, verified data integrity, and resolved initial schema mismatches directly inside the database tool.
* **Advanced Data Pipeline Scripting:** Wrote standalone SQL scripts utilizing `INNER JOIN` operations to blend disconnected datasets, data aggregations (`GROUP BY`, `COUNT`, `SUM`), and filter constraints (`HAVING`).
* **Algorithmic GPA Mapping:** Formulated a multi-level conditional SQL `CASE` statement to dynamically translate string text letter grades (A, B, C, etc.) into a standard 4.0 GPA scale.
* **Executive Dashboard Deployment:** Connected clean database pipelines to construct an interactive, presentation-ready Business Intelligence (BI) dashboard for university decision-makers.
